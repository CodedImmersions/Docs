## Compatibility
This plugin supports Unity 2021.3 LTS to 7000.0+.<br/>
With this plugin, you can choose whether to use the C SDK or the C# SDK.

::: info
For 2021.3 to 6000.7, the C SDK is your only option. But, if you're on 7000.0+, you have access to both. This is due to
Unity 7.0 and above supporting .NET 10, which the C# SDK requires.
:::
